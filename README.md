# 剪贴板文本清理守护 (Clipboard Text Cleaner)

一个 Windows 下的剪贴板文本清理守护脚本：**在后台运行，复制即自动清理，粘贴就是干净文字。**

复制网页、PDF、聊天记录里的文字时，经常带着恼人的空格、换行和段落标记（¶ · ■ 等）。这个脚本监听剪贴板，一旦发现你复制了新文字，就自动清理并写回剪贴板——之后直接 `Ctrl+V` 粘贴出来的就是干净的结果，全程无感。

## ✨ 特性

- 🔄 **后台自动监听**：每 0.4 秒检查一次剪贴板，复制后秒级清理
- 🚫 **防循环机制**：清理结果不会被重复处理
- 🖼️ **只处理文字**：图片、文件等其他剪贴板内容不受影响
- 📦 **零依赖**：纯 Python 标准库 + Windows API（ctypes），无需安装任何第三方库
- ⚙️ **规则可调**：命令行参数自由组合，想保留什么就保留什么

## 📋 清理规则

默认规则：
- ✂️ 删除所有空格（含全角空格 `　`、不间断空格等）
- ✂️ 删除所有换行（`\r\n` / `\r` / `\n`）
- ✂️ 删除制表符（Tab）
- ✂️ 删除常见段落/项目符号：`¶ · ■ ▶ ● ◆ ▲ ► ‣ ▪`
- ✂️ 去除首尾空白

## 🚀 使用方法

### 启动守护

```bash
python clipboard-cleaner.py
```

启动后保持窗口开着即可。之后正常复制文字，粘贴出来的就是清理结果。

**停止**：在脚本窗口按 `Ctrl+C`，或直接关闭窗口。

### 可选参数

| 参数 | 效果 |
|------|------|
| `--space` | 保留空格（不删） |
| `--keep-newline` | 保留换行（不删） |
| `--keep-para` | 保留段落标记（不删） |
| `--collapse` | 不删换行，只把连续空行合并为一个 |
| `--quiet` | 不打印清理日志 |

示例——只去掉空格和段落标记、保留换行：

```bash
python clipboard-cleaner.py --keep-newline
```

### 运行日志

每次自动清理会在窗口打印一条记录：

```
[14:29:07] 已清理 256 -> 198 字符
```

## 💻 环境要求

- Windows 10 / 11
- Python 3.6+

## ⚠️ 注意事项

- 脚本只处理纯文本剪贴板内容，复制图片/文件时不会做任何事
- 剪贴板偶尔会被其他程序短暂占用，脚本会自动跳过重试
- 如果某些文字你需要保留格式，运行前先加对应参数，或直接关掉守护
